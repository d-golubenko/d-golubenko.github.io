# Персональный академический сайт

Академический сайт Daniil Golubenko на английском языке. Статические HTML и CSS без сборки и дополнительных библиотек, с оформлением в стиле конца 1990-х.

## Хранение и размещение

- Репозиторий: https://github.com/dgolubenko99/academic-homepage
- Доступ: Private. Основная ветка: main.
- План размещения: Cloudflare Workers Static Assets с подключением к GitHub.
- Публикация и аналитика Cloudflare пока не настроены.

После настройки Cloudflare сайт будет доступен посетителям по публичному адресу, а репозиторий останется закрытым.

## Файлы

- index.html — главная страница, биография, исследовательские интересы, избранные публикации и контакты.
- styles.css — оформление и адаптация под телефон.
- publications.html — полный список из 47 публикаций с DOI.
- acid-recovery.html — извлечение кислоты из модельного выщелачивающего раствора литиевых батарей.
- selective-ion-transport.html — селективный перенос одновалентных катионов через PBI-модифицированную мембрану.
- reverse-electrodialysis.html — мембраны для получения энергии из градиента солёности.
- selectivity-measurement.html — влияние условий измерения на хлорид/сульфатную селективность.
- pei-brine-mining.html — алкилированные PEI-мембраны для электродиализа модельного рассола.
- .gitignore — исключения для временных файлов, зависимостей и секретов при использовании Git.
- .nojekyll — совместимость с GitHub Pages, если потребуется такой способ размещения.

Пять исследовательских страниц содержат самостоятельные английские описания, результаты с интерпретацией, условия экспериментов, ссылки на источники и структурированные данные Schema.org. Исходные рукописи и дополнения в состав сайта не входят.

## Просмотр и обновление

Откройте index.html двойным щелчком для просмотра в браузере. Переходы между страницами работают локально.

Изменяйте HTML в текстовом редакторе, сохраняйте в UTF-8 и обновляйте страницу в браузере. Не меняйте расширение на .txt. Здесь можно сообщать изменения ассистенту, который обновляет локальные файлы.

Чтобы сохранить изменения на GitHub, откройте репозиторий и выберите Add file → Upload files, загрузите изменённые файлы в корень и нажмите Commit changes. Commit — сохранённая версия изменений с коротким описанием. .gitignore не защищает от ручной загрузки через браузер: выбирайте только нужные файлы сайта.

После подключения GitHub к Cloudflare изменения в ветке main будут запускать обновление сайта. Пока подключение не настроено, загрузка на GitHub только сохраняет файлы в репозитории.

При редактировании через GitHub локальная копия сама не обновляется. Пароли, токены и исходные рукописи не включайте в сайт.

## Следующие шаги

1. Подготовить конфигурацию Cloudflare Workers Static Assets.
2. Подключить репозиторий к Cloudflare и проверить публичный сайт.
3. Выбрать постоянный адрес и добавить canonical-ссылки, sitemap.xml и robots.txt.
4. Подключить Cloudflare Web Analytics и инструменты индексации поисковиков.
